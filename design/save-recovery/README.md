# 保存失败提示

Pen 节点 `OspP2`（31）：工作区顶栏下的紧凑恢复提示，中英文并列样例。PNG 为 `OspP2.png`。

- 默认高度52px，左右12px内边距、9px圆角。错误原因13px，操作12px。
- 右侧仅一个 secondary“重试保存”。技术详情默认折叠，展开最多120px高并允许滚动、复制；不把私有路径常驻显示。
- 空间不足提示释放空间；权限失败提示检查项目目录权限；其它失败提示重试。
- 保存失败不提供丢弃修改或关闭提示操作。重试成功自动移除提示，并恢复剪辑编辑。
- 页脚在保存失败时不重复显示重试按钮。正常保存仍保留原有Saving状态。

## 导入失败

同一画板追加中英文导入失败样例。复用52px紧凑提示，右侧 secondary“选择其它音频”；技术详情折叠。按损坏/不支持、文件不存在、访问权限、空间不足给出恢复方向。重新选择时清除旧错误，取消不创建项目，成功导入或打开已有项目后移除提示。
