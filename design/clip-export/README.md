# 08 · 导出选中剪辑

更新 `Printemps.pen` 中的画板 `S5oPw`；旧整轨导出设计保留在独立归档画板 `k5wPO`。当前导出 PNG 同步到 `exports/08-export.png`。

- 从工作台或历史页选择可用剪辑后打开，520px 弹窗，28px 内边距、16px 圆角；不再显示整轨多选与整页导航。
- 显示剪辑当前名称、格式化片段时长、实际采样率和声道数。截图示例为主唱片段 2、44 秒；不代表实测模型性能。
- WAV/FLAC 使用圆角底板和蓝色移动选中块，200ms；支持键盘方向键，减少动态效果时关闭动画。
- 关闭（secondary）与导出（primary）靠右，间距8px；点击导出后使用系统目录选择器。无需另行配置私有结果路径。
- 仅输出剪辑的源入点到源出点，文件从0开始，不补时间轴 offset；保留原本的试听音量与静音不影响导出的规则。
- 导出中禁用重复提交和关闭；失败保留格式并给出下一步提示；成功后显示“打开文件夹”；下一次目录选择取消时清除旧成功状态和打开目录入口。
