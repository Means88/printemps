## 快捷键

应用工作区内生效，不注册系统后台快捷键。编辑文本/数值、滑块、开关、菜单及弹窗保留自己的按键行为。

| 按键 | 操作 |
| --- | --- |
| Space | 播放 / 暂停 |
| Home | 返回起点 |
| ← / → | 前后 1 秒 |
| Shift + ← / → | 前后 10 秒 |
| I / O | 设置入点 / 出点 |
| L | 开关循环 |
| + / − | 放大 / 缩小 |
| 0 | 适配整段音频 |
| T | 音轨列表 |
| ? | 快捷键说明 |

Space 参考 Adobe Audition 的默认播放/停止惯例；其余为 Printemps 的固定首版映射，不宣称兼容某一 DAW 全套键位。
来源：https://helpx.adobe.com/audition/desktop/keyboard-shortcuts/default-keyboard-shortcuts.html

## 28 · 原生菜单栏

设计源为 `../Printemps.pen` 的画板 28，结构预览为 `Hq9L2.png`。使用 Electron 原生菜单：macOS 放入系统菜单栏，Windows/Linux 放入窗口菜单栏，视觉由操作系统绘制。

- 文件：导入音频（Cmd/Ctrl+O）、全部项目（Cmd/Ctrl+Shift+O）、导出音轨（Cmd/Ctrl+Shift+E）、关闭窗口。
- 编辑：系统输入框撤销、重做、剪切、复制、粘贴、全选；不代表音轨编辑历史。
- 播放：播放/暂停、返回起点、循环、入点、出点、节拍器。
- 音轨：所有音轨（Cmd/Ctrl+Shift+T）、分离所选音轨、节奏与调性。
- 视图：时间轴缩放、显示完整音频、音轨详情、全屏。
- 工具／帮助：模型管理、设置（Cmd/Ctrl+,）、快捷键、关于；macOS 设置和关于位于应用菜单，另保留系统窗口菜单。

无项目、弹窗打开、音频加载期间按上下文禁用命令；分离中禁用重复分离。循环、节拍器、详情显示为勾选项。中英文随应用语言切换。空格、I/O、L 等单键沿用工作区键盘处理，不注册为原生全局快捷键，避免在输入文字时误触。导入新项目前等待当前编辑保存。

验证：66 项测试通过，生产构建通过。macOS 独立测试包验证了原生菜单、设置入口、无项目/弹窗禁用状态和英文切换；Windows/Linux 的菜单分支已测试，尚未进行对应平台 GUI 验收。

## 30 · 多剪辑与片段处理

设计源 `Printemps.pen` 画板 30（ymoeh），预览 `ymoeh.png`。点击波形片段选择剪辑；在游标处点击“分割”或按 S；拖动左右边缘调整源入点/出点，右侧也可精确输入秒数。裁剪为非破坏式编辑，保留私有源文件。

右侧显示剪辑名称、时间轴 offset、时长及源范围。分离与导出作用于选中剪辑；导出对话框显示剪辑名称及实际时长。分离结果从原剪辑 offset 开始，结果内部源范围从零开始。二次分离隐藏选中来源剪辑，保留同轨其它片段；来源轨没有可见片段时才隐藏整轨。

原始/分轨禁用规则保持；编辑期间与分离期间避免并发更改片段。旧项目兼容整轨单片段。当前不提供移动片段、交叉淡化或剪辑撤销历史。设计示例波形并非推理结果。
