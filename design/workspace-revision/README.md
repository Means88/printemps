# 工作区修订 — 2026-09-20

先修改当前 Pen 文档，再实现桌面应用。新增画板 23（工作区 Ac4ta）、24（音轨列表 a8n0bQ）、25（节奏与调性 kdPq6）、26（快捷键 cFom6），以及进度条状态 UB3LA。PNG 是可编辑 Pen 画板的导出；波形、进度均为设计示例。

- 二次分离：A 保留为隐藏轨道，原位置插入「其它 C、目标 B」，隐藏的 A 紧随结果。隐藏轨道不参与混音，包括独奏判定；可恢复显示。失败和取消不隐藏来源。
- 音轨列表：拖动手柄排序，目标行上半区插入前、下半区插入后；上下按钮提供键盘替代。色条与波形一致，Other 使用 #4DD6BA。显示开关独立于静音；删除需确认，原始轨道受保护，有任务或导出时拒绝删除。
- 原始/分轨互斥试听：另一组整体置灰、禁用编辑/音量/S/M/分离及单轨导出；静音轨道仅将波形置灰。S/M 有着色 hover 状态。
- 底部统一 32px 控件：返回、播放、循环、入点、出点。循环与入出点靠近播放按钮。分离/导出/分析按钮缩小；进度宽度 240ms ease-out，末端圆角，减少动态效果偏好关闭过渡。
- 波形区滚轮缩放；触摸板 pinch（Ctrl-wheel）缩放，横向手势保持平移，缩放锚点保持在指针附近。
- 节拍器开启后作为固定顺序的首轨显示，不属于可分离/导出/排序的音频轨道。使用与音轨一致的推子、双击归零、dB 直接编辑。节奏弹窗仅保留开关，音量不再重复展示。
- 节奏弹窗：节奏组中 BPM/拍号双列，第一拍与游标按钮同排；调性独立分组；分析推荐星标保留。字段失焦保存并校验。

## 快捷键

应用工作区内生效，不注册系统后台快捷键。编辑文本/数值、滑块、开关、菜单及弹窗保留自己的按键行为。

| 按键 | 操作 |
| --- | --- |
| Space | 播放 / 暂停 |
| Home | 返回起点 |
| ← / → | 前后 1 秒 |
| Shift + ← / → | 前后 10 秒 |
| I / O | 设置入点 / 出点 |
| L | 开关循环 |
| + / − | 放大 / 缩小 |
| 0 | 适配整段音频 |
| T | 音轨列表 |
| ? | 快捷键说明 |

Space 参考 Adobe Audition 的默认播放/停止惯例；其余为 Printemps 的固定首版映射，不宣称兼容某一 DAW 全套键位。
来源：https://helpx.adobe.com/audition/desktop/keyboard-shortcuts/default-keyboard-shortcuts.html

单元测试覆盖隐藏来源保留、隐藏独奏排除、排序/删除约束、并发元数据保存、节拍器运行时启停及音量变化。62 项测试通过，2 项集成测试按默认配置跳过。浏览器预览已检查 1280×800 中文和 1440×900 英文布局、真实指针拖动排序、隐藏、焦点在播放按钮时的 Space。预览音频是合成示例，不是分离性能测试。扬声器实际听感仍需桌面试听确认。
