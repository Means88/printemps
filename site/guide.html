1. 安装

  • 系统要求：macOS 14 或更高（Apple 芯片）、Windows 10 或更高（x64）、Linux x64。分离模型按需下载，每个声部的权重约几百 MB 到 1 GB 多，请预留磁盘空间。
  • macOS：打开 DMG，把 Printemps 拖到「应用程序」。当前版本已签名但未经 Apple 公证，首次打开若提示无法验证开发者，请到「系统设置 › 隐私与安全性」底部点「仍要打开」，之后正常双击即可。
  • Windows：运行安装程序（.exe），按向导完成；SmartScreen 提示时选择「更多信息 › 仍要运行」。
  • Linux：下载 AppImage，赋予执行权限后运行：
chmod +x Printemps-*.AppImage && ./Printemps-*.AppImage

2. 首页与导入

  1. 启动后进入首页。点击「选择音频文件」，或把音频拖放到虚线区域；也可用菜单「文件 › 导入音频…」（⌘O）。
  2. 支持 WAV、FLAC、MP3、M4A、AIFF、OGG。每个项目只包含一个音频文件；导入后自动创建项目并直接进入工作台。
  3. 首页下方列出最近项目，可搜索；「全部项目」进入完整的历史页（见第 10 节）。

导入时应用会把音频复制到自己的私有目录，原文件不会被修改。

3. 工作台一览

  • 顶栏：左上角箭头返回首页，点击 Printemps 标志也能回到首页；项目名旁的铅笔可原位改名。右侧是「分析」（节奏与调性）与「导出」（导出音轨）。
  • 工具栏：「音轨列表」、试听来源「原始 / 分轨」切换、时间显示格式（时分秒 / 小节与拍）、节拍器开关、「分割」；右侧为时间轴缩放。
  • 时间轴：最上方是节拍器轨，其下是原始音频轨与各声部结果轨。点击或按住刻度尺拖动可定位播放头，分离进行中也可以。
  • 剪辑详情：右侧面板显示选中剪辑的名称、起始位置、时长、源入点/出点，以及「分离」「导出剪辑」按钮。
  • 传输条：底部有返回起点、播放/暂停、循环、入点/出点、时间码与总音量。

4. 选择声部与分离

  1. 在时间轴上选中一个剪辑（首次导入时就是整段原始音频），点击右侧面板的「分离」，或用菜单「音轨 › 分离所选剪辑…」。
  2. 在弹窗中勾选想要的声部。可按名称、英文名或乐器类别搜索，也可按分类浏览。下方的分离摘要会显示已缓存和待下载的模型数量、本次下载大小和将使用的处理设备。
  3. 点击开始。缺少的模型会先下载（可取消），下载完成后自动开始分离。进度显示在工作区的进度行里；期间可以继续试听和定位播放头。
  4. 完成后每个声部成为一条独立音轨，并额外生成一条 Other（残差）轨，包含未被选中声部的剩余部分。

二次分离：可以对分离结果中的某一剪辑再次分离（例如从「鼓组」里再提取「底鼓」）。来源剪辑会保留，新结果按原位置插入。

分离失败或被取消时，进度行会给出「重试」或「关闭」；应用中途退出后重新打开，未完成的任务会标记为「已中断」，可以重试。

5. 试听

  • Space 播放/暂停，Home 回到起点，←/→ 前后 1 秒，加 Shift 为 10 秒。
  • 原始 / 分轨：在原始音频与分离结果之间切换试听，比较分离效果。
  • 每条音轨有 S（独奏，只听开启独奏的轨）、M（静音）和增益滑块；底部有总音量。
  • 循环：I / O 设置入点与出点，L 或传输条上的循环按钮开启循环。
  • 缩放：+ / − 放大缩小，0 显示完整音频；触控板捏合与滚轮同样有效。

6. 剪辑编辑

  • 选中：点击剪辑；右侧面板显示详情。
  • 分割：把播放头移到目标位置，按 S 或点击工具栏「分割」。
  • 调整首尾：拖动剪辑两端的把手；需要精确到毫秒时，在剪辑详情里直接输入「源入点」「源出点」后按回车。
  • 改名：点击剪辑名旁的铅笔图标，回车确认，Esc 取消。
  • 只处理一段：选中一段剪辑后再「分离」或「导出剪辑」，只会处理该段范围；结果会放在时间轴上相同的位置（offset 保持一致）。

7. 节奏与调性

  • 点击顶栏「分析」，应用在本机估计 BPM、调性、拍号与第一拍位置。分析不会自动运行，只在你点击时进行。
  • 结果显示在顶栏（如 120 BPM、G 大调、4/4）。点击这些控件打开「节奏与调性」弹窗手动修改，或「复位」回到分析推荐值。修改只影响刻度与节拍器，不改变音频速度或音高。
  • 速度不稳定、节拍信息不足等情况会给出提示，此时可以手动填写。
  • 时间显示切换为「小节与拍」后，刻度尺按拍号显示小节。
  • 节拍器：工具栏开关打开，随播放发出点击音；节拍器轨上可调音量。

8. 音轨列表

按 T、点击工具栏「音轨列表」或菜单「音轨 › 所有音轨…」打开。这里可以：

  • 拖动或用上下按钮排序；
  • 显示 / 隐藏音轨。隐藏只影响工作区与试听，可随时恢复；
  • 删除结果音轨（不可撤销；原始音轨不可删除）。

9. 导出

导出总是生成独立的 WAV（24 bit）或 FLAC 文件副本，写到你选择的导出目录；应用私有目录里的结果不受影响。

  • 导出剪辑：选中剪辑后点右侧面板「导出剪辑」，或 ⌘⇧E。只导出该剪辑的范围。
  • 导出音轨：顶栏「导出」。勾选要导出的分离结果音轨（不含原始音频），每条可见剪辑各成一个文件。
  • 对齐：两种导出都可以选择「剪辑范围」（文件从剪辑开头开始）或「项目时间轴」（按剪辑在项目里的位置在开头补空白，方便直接拖进 DAW 对齐）。
  • 完成后可「打开文件夹」。导出目录可在设置中更改。

10. 项目管理

  • 首页「全部项目」或 ⌘⇧O 进入历史页。可按名称搜索、按任务状态或有无结果筛选、按时间或名称排序。
  • 每个项目卡片可以直接打开、改名、导出剪辑或删除。
  • 删除的项目进入「已删除」列表，可随时恢复；也可勾选「同时清理应用保存的试听结果」或在已删除页中永久清除，彻底移除本地文件。
  • 项目在编辑时自动保存；保存失败会在工作区顶部提示并提供「重试保存」。

11. 模型管理

顶栏的模型图标、菜单「工具 › 模型管理…」打开模型管理页。

  • 列出全部目标声部及其模型：已缓存的排在前面，显示权重大小；未下载的可以提前下载，不再需要的可以删除缓存。
  • 可按名称或乐器搜索、按缓存状态筛选。
  • 模型存储位置可更改（例如移到外接硬盘）；更改后已下载的模型需要重新下载或手动移动。

12. 设置

顶栏齿轮或 ⌘, 打开设置。

  • 界面语言：中文 / English，即时切换。
  • 处理设备：自动选择（会显示当前实际会用的设备）、CPU、NVIDIA CUDA（有 NVIDIA 显卡的 Windows/Linux）、Apple MPS（实验性，Apple 芯片 Mac）。自动选择不会选用 MPS。
  • 网络代理：下载模型时使用。可跟随系统、不使用代理，或填写自定义地址（http、https、socks5，可带用户名密码，如 http://127.0.0.1:7890）。
  • 模型缓存目录与导出目录。
  • 更新：检查、下载并在重启后安装新版本。

14. 常见问题

  • macOS 提示无法打开：当前版本未公证，按第 1 节到「隐私与安全性」放行一次即可。
  • 模型下载失败：检查网络后点「重试下载」；已下载完成的部分会保留，继续下载剩余文件。需要走代理时在设置的「网络代理」里填写地址。
  • MPS 很慢或不稳定：把处理设备改为 CPU；MPS 仍是实验性选项。
  • 分离被中断：重新打开项目后在进度行点「重试」，来源音轨已保留。
  • 保存失败：多为目录只读或磁盘已满，处理后点「重试保存」；重启后数据仍在。
  • 数据在哪：macOS ~/Library/Application Support/printemps，Windows %APPDATA%\printemps，Linux ~/.config/printemps；处理方式详见隐私政策。

其它问题请到 GitHub Issues 反馈。

1. Install

  • Requirements: macOS 14 or later (Apple silicon), Windows 10 or later (x64), Linux x64. Separation models download on demand; each stem’s weights are a few hundred MB to just over 1 GB, so keep disk space free.
  • macOS: open the DMG and drag Printemps into Applications. The current build is signed but not yet notarized by Apple. If the first launch says the developer cannot be verified, go to System Settings › Privacy & Security and click “Open Anyway” at the bottom; afterwards it opens normally.
  • Windows: run the installer (.exe) and follow the wizard. If SmartScreen appears, choose More info › Run anyway.
  • Linux: download the AppImage, make it executable and run it:
chmod +x Printemps-*.AppImage && ./Printemps-*.AppImage

2. Home and import

  1. The app opens on the Home page. Click Choose audio file, or drop a file onto the dashed area; File › Import audio… (⌘O) works too.
  2. WAV, FLAC, MP3, M4A, AIFF and OGG are accepted. Each project holds exactly one audio file; importing creates the project and opens the workspace immediately.
  3. Below the import area, Recent projects lists your work and can be searched; All projects opens the full history page (section 10).

Importing copies the audio into the app’s private folder; the original file is never modified.

3. The workspace

  • Header: the arrow at the top left returns Home, as does clicking the Printemps logo; the pencil next to the project name renames it in place. On the right are Analyze (rhythm and key) and Export (export tracks).
  • Toolbar: Tracks, the monitoring source switch Original / Stems, time display format (Time / Bars & beats), the metronome switch and Split; zoom controls sit on the right.
  • Timeline: the metronome lane on top, then the original audio track and one track per separated stem. Click or press-and-drag the ruler to move the playhead, even while a separation is running.
  • Clip details: the right panel shows the selected clip’s name, offset, duration, source in/out, and the Separate and Export clip buttons.
  • Transport: return to start, play/pause, loop, in/out, the timecode and master volume along the bottom.

4. Choose stems and separate

  1. Select a clip on the timeline (right after import that is the whole original audio) and click Separate in the right panel, or use Tracks › Separate selected clip….
  2. Tick the stems you want. Search by name, model id or instrument family, or browse by category. The summary at the bottom shows how many models are cached or still to download, the download size and the processing device.
  3. Start. Missing models download first (cancellable) and separation begins automatically afterwards. Progress appears in the workspace lane; you can keep auditioning and moving the playhead meanwhile.
  4. Each stem becomes its own track, plus an extra Other (residual) track containing everything you did not select.

Secondary separation: you can separate a clip on a result track again (for example extract the kick from Drums). The source clip is kept and the new results are inserted at the same position.

If a separation fails or is cancelled the lane offers Retry or Close. If the app quits mid-task, the task is marked Interrupted on the next launch and can be retried.

5. Audition

  • Space plays/pauses, Home returns to the start, ←/→ seek 1 second and 10 seconds with Shift.
  • Original / Stems switches monitoring between the untouched audio and the separated result.
  • Each track has S (solo: hear only soloed tracks), M (mute) and a gain fader; master volume is in the transport bar.
  • Loop: I / O set the in and out points, L or the loop button toggles looping.
  • Zoom: + / −, 0 fits the whole audio; trackpad pinch and the scroll wheel work as well.

6. Edit clips

  • Select a clip by clicking it; details appear on the right.
  • Split: move the playhead and press S or click Split in the toolbar.
  • Trim: drag the handles at either end, or type exact Source in / Source out values in Clip details and press Enter for millisecond precision.
  • Rename: click the pencil next to the clip name, Enter to confirm, Esc to cancel.
  • Work on one section: with a trimmed clip selected, Separate or Export clip processes only that range; results land at the same position on the timeline (the offset is preserved).

7. Rhythm and key

  • Click Analyze in the header to estimate BPM, key, time signature and the first beat locally. Analysis only runs when you ask for it.
  • Results show in the header (for example 120 BPM, G major, 4/4). Click them to open Rhythm & key, edit the values by hand or Reset to the recommendation. Edits only affect the ruler and metronome, never the audio’s speed or pitch.
  • Variable tempo or too few beats are reported so you can fill the values in yourself.
  • Switching the time display to Bars & beats lays the ruler out in bars according to the time signature.
  • Metronome: the toolbar switch adds clicks during playback; its volume is on the metronome lane.

8. Track list

Press T, click Tracks in the toolbar or use Tracks › All tracks…. Here you can:

  • reorder by dragging or with the arrow buttons;
  • show / hide tracks (hidden tracks leave the workspace and mix and can be shown again any time);
  • delete result tracks (cannot be undone; the original track cannot be deleted).

9. Export

Exports always create independent WAV (24 bit) or FLAC copies in the export folder you choose; the results in the app’s private folder are untouched.

  • Export clip: select a clip and click Export clip in the right panel, or press ⌘⇧E. Only that clip’s range is exported.
  • Export tracks: the header’s Export button. Tick the result tracks to export (the original audio is not included); every visible clip becomes its own file.
  • Alignment: both dialogs offer Clip range (files start at the clip) or Project timeline (leading silence pads each file to its position in the project, so it drops straight into a DAW aligned).
  • When finished, Open folder reveals the files. Change the export folder in Settings.

10. Manage projects

  • All projects on the Home page, or ⌘⇧O, opens the history page. Search by name, filter by task state or by whether results exist, sort by time or name.
  • Each project card can be opened, renamed, exported or deleted directly.
  • Deleted projects move to the Deleted list and can be restored any time. Tick “also remove the audition results the app saved” or purge from the Deleted list to remove the local files for good.
  • Projects save automatically as you edit. If a save fails, a banner at the top of the workspace offers Retry save.

11. Model library

Open it from the header’s model icon or Tools › Model library….

  • Every target stem and its model is listed, cached ones first with their weight size. Download models ahead of time or delete caches you no longer need.
  • Search by name or instrument and filter by cache state.
  • The model cache folder can be moved (to an external drive, for instance); after moving it, cached models must be re-downloaded or moved by hand.

12. Settings

Open Settings from the header’s gear or ⌘,.

  • Interface language: 中文 / English, switched immediately.
  • Processing device: Automatic (shows which device it will actually use), CPU, NVIDIA CUDA (Windows/Linux with an NVIDIA GPU) or Apple MPS (experimental, Apple silicon). Automatic never picks MPS.
  • Network proxy: used when downloading models. Follow the system, use no proxy, or enter a custom address (http, https or socks5, optionally with credentials, e.g. http://127.0.0.1:7890).
  • Model cache folder and export folder.
  • Updates: check, download and install on restart.

14. Troubleshooting

  • macOS refuses to open the app: the build is not notarized yet; allow it once under Privacy & Security as described in section 1.
  • Model download failed: check the connection and click Retry download; finished files are kept and only the rest is downloaded. If you need a proxy, set it under Network proxy in Settings.
  • MPS is slow or unstable: switch the processing device to CPU; MPS remains experimental.
  • Separation interrupted: reopen the project and click Retry in the progress lane; the source track is retained.
  • Save failed: usually a read-only folder or a full disk; fix it and click Retry save. Data survives a restart.
  • Where is my data: ~/Library/Application Support/printemps on macOS, %APPDATA%\printemps on Windows, ~/.config/printemps on Linux; see the privacy policy for details.

For anything else, open an issue on GitHub.
