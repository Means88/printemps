## 性能与平台边界

纯分割且采样位置不变时复用解码缓冲；删除音轨会释放不再引用的解码缓存。六条十分钟立体声、每轨60片段、20次重建的真实Float32Array压力测试通过；单轨裁剪增加一份211,680,000字节缓冲。此测试不包含Electron解码、设备播放或进程峰值；多轨裁剪仍可能同时保留源和时间轴PCM。

Linux历史构建对0.1.0→0.1.1差分重建：3,045,393,708字节安装包，传输10,940,143字节，16次请求，SHA-512一致。99.641%的节省只属于该构建对，不是未来更新承诺。缺旧包/损坏blockmap回退全量、篡改响应拒绝校验已有验证。

macOS最低版本14.0。本机CPU推理已验证；CUDA、MPS及Windows/Linux桌面设备不能从CI构建成功推定可用。Linux桌面入口无无条件 `--no-sandbox`，实际用户命名空间与沙箱行为仍待原生环境检查。
