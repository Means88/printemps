## 差分更新与平台边界

Linux 本地实际 AppImage 差分重建证据位于 `.cache/linux-verification/history-recovery/`：从 0.1.0 重建 3,045,393,708 字节安装包，传输 10,940,143 字节（含元数据），16 次请求，节省 99.641%，SHA-512 一致。这只证明该构建对的下载与重建，不代表真实安装升级或未来更新比例。

AppImageUpdater 旧包缺失、旧 blockmap 损坏时回退全量，以及内容被篡改时拒绝校验，均有测试与 Linux CI 证据。AppImage 桌面入口已验证为 `Exec=AppRun %U`，移除了无条件 `--no-sandbox`；打包工具仍可能在用户命名空间不可用时回退，实际系统沙箱待原生 Linux 验证。

本机 CPU 已运行真实推理；CUDA 实机未验证，MPS 未通过本机验证，仍属实验选项。当前 macOS 包最低系统版本为 14.0。Windows/Linux 安装、桌面、音频设备及升级测试尚缺真实环境证据。
